# Code of Conduct — BLACKCHAIN (DRAFT v0.1)

Kami berkomitmen pada lingkungan yang terbuka, aman, dan saling menghormati
untuk semua kontributor, tanpa memandang latar belakang.

- Bersikaplah hormat dan profesional; kritik ditujukan pada ide, bukan orang.
- Tidak ada pelecehan, diskriminasi, atau intimidasi dalam bentuk apa pun.
- Laporkan perilaku yang melanggar lewat kanal resmi proyek.
- Pelanggaran dapat berujung pada dikeluarkan dari komunitas dan program
  kontribusi (termasuk airdrop).
